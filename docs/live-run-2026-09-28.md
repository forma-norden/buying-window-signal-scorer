# Bounded live checks: growth and hiring profiles

Three bounded scans ran on 28 September 2026 through SearchApi Google Jobs and Google News. Raw API responses and the key remain in ignored local `data/` files.

| Scan | UTC time | Jobs requests | News requests | Relevant, deduplicated jobs | Selected employers | Failed requests |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| Growth & expansion, United States, three-company cap | 11:41 | 2 | 3 | 19 | 3 | 0 |
| Hiring & team buildout, United States, three-company cap | 11:42 | 2 | 3 | 16 | 3 | 0 |
| Growth & expansion, United States, follow-up | 12:02 | 2 | 3 | 18 | 3 | 0 |

The growth scans used the `growth` preset with `max_accounts=3` and `max_requests=20`. The hiring scan used the `hiring` preset with `max_accounts=3` and `max_requests=8`. All used the preset role searches, event groups and one-page-per-query behaviour in the repository. The selected growth employers scored 45 from dated, strong-title matches; none received qualified news points. The hiring profile surfaced different roles and employers.

The observed request count was five for each scan, within the preflight upper bound of five initial searches for these settings. Results will change as Jobs and News results change. `job_count` counts deduplicated listings that matched the profile's strong or adjacent titles across the returned responses; it does not count distinct companies.

To run a comparable growth search, start with the default profile and use:

```bash
python -m buying_window.cli scan --mode discovery --max-accounts 3
```

To try hiring, choose **Hiring & team buildout** in the dashboard and set the discovery-account limit to three. The scan estimate will show the planned requests before you run it. [SearchApi Jobs documentation](https://www.searchapi.io/docs/google-jobs) and [News documentation](https://www.searchapi.io/docs/google-news) describe the two data sources.
